3. 같은건 매번 새로 요청하지 않기

- 3.1 CDN/HTTP Cache

  - CloudFront Custom Cache Policy 적용

    - CloudFront 최초 요청: x-cache: Miss from cloudfront
    - 이후 요청: x-cache: Hit from cloudfront

  - 정적 리소스 캐시 정책

    - webpack 빌드 결과물에 contenthash 적용

      - 리소스 변경시 url 도 변경하여 이전 버전의 캐시가 제공되는 문제를 막기 위한 해결책

    - S3 cache-control 설정

      - index.html: Cache-Control: no-cache
      - 나머지 resource: Cache-Control: public, max-age=31536000, immutable

      - 적용전:
        - main.[contenthash].js 의 response headers에 cache-control 없음
        - 재요청 시 서버 재검증 요청 발생
          - Status Code: 304
          - Size: 0.3 kB
